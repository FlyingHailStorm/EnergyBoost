# Piggy Power 🐷⚡

A playful, mobile-friendly energy top-up page from Rooster to Piggy. Built as a single static HTML file, with no dependencies, analytics, sign-in, or data collection.

## Run locally
Open `index.html` in any modern browser.

## Deploy with Cloudflare Pages
1. In Cloudflare, go to **Workers & Pages** > **Create** > **Pages** > **Connect to Git**.
2. Select `FlyingHailStorm/EnergyBoost`.
3. Choose **None** for framework, leave **Build command** blank, and set **Build output directory** to `/` (repository root).
4. Deploy. Cloudflare will provide a `*.pages.dev` address to share.

Alternatively, deploy via GitHub Pages: Settings > Pages > Deploy from branch > main > /(root). The page should be available at `https://flyinghailstorm.github.io/EnergyBoost/` after publication.
