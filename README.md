# Piggy Power — enhanced

A static, mobile-friendly website for Cloudflare Workers static assets, Pages or GitHub Pages.

## Deploy
Upload `index.html` and `rooster-reunion.wav` to the repository root, replacing `index.html`. Keep the WAV alongside the HTML. Your existing GitHub-to-Cloudflare deployment should publish automatically if configured to use these static files.

## Features
- Energy button alternates `TOP UP MY ENERGY +100` and `I WANT TO SEE MY MAN!` on successive presses.
- The Rooster runs toward Piggy facing her, with randomized kiss, hug or heart surprises and the existing original WAV jingle.
- Daily Mystery Gift shows a deterministic surprise for each local calendar day. No account or tracking required.
- Emergency Rooster Hotline delivers randomized encouraging messages.
- Accessible buttons, live result announcements and reduced-motion support.

No server, third-party libraries, cookies, analytics or personal information needed.
