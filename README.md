# EnergyBoost — Coffee, Goodnight and Mobile Polish

Deploy by replacing `index.html` in FlyingHailStorm/EnergyBoost and keeping `rooster-reunion.wav` in the same directory.

Includes all existing features: alternating energy/reunion button, Rooster facing Piggy, kiss/hug/hearts, WAV jingle, daily mystery gift, hotline.

New:
- Coffee Delivery: Rooster runs over with coffee; every third delivery has a comic spill.
- Goodnight Kiss: Rooster delivers a bedtime kiss in a moonlit scene.
- Mobile polish: better tap targets, responsive spacing, more separation between the main button and message, reduced-motion support.

No external dependencies or tracking. Tested for HTML structure and JavaScript syntax; please verify visual animations on your phone after deployment.
